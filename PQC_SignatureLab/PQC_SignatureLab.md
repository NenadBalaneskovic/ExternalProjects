    "# 🧩 **NIST PQC Signature Standards — Deep Technical Report**\n",
    "\n",
    "The three NIST‑standardized PQC signature algorithms — **Dilithium**, **Falcon**, and **SPHINCS+** — represent three fundamentally different mathematical worlds:\n",
    "\n",
    "- **Dilithium** → lattice‑based (Module‑LWE / Module‑SIS)  \n",
    "- **Falcon** → lattice‑based (NTRU + GPV sampling)  \n",
    "- **SPHINCS+** → hash‑based (Merkle trees, WOTS+, FORS)\n",
    "\n",
    "Each algorithm solves PQC differently — with distinct trade‑offs in performance, signature size, security assumptions, and implementation complexity.\n",
    "\n",
    "---\n",
    "\n",
    "# 🧠 **Why Three Algorithms?**\n",
    "\n",
    "Because **no single PQC signature scheme fits all use cases**.\n",
    "\n",
    "- **Dilithium** → the practical all‑rounder  \n",
    "- **Falcon** → the high‑performance, small‑signature champion  \n",
    "- **SPHINCS+** → the conservative fallback with minimal assumptions  \n",
    "\n",
    "Together they form a robust PQC ecosystem.\n",
    "\n",
    "---\n",
    "\n",
    "# 🧬 **1. Dilithium — The Robust Lattice Standard**\n",
    "\n",
    "## Mathematical Foundation  \n",
    "Dilithium is built on **Module‑LWE** and **Module‑SIS**, two lattice problems believed to be hard even for quantum computers.\n",
    "\n",
    "### Module‑LWE  \n",
    "Given:\n",
    "\n",
    "$A \\cdot s + e \\pmod{q}$\n",
    "\n",
    "Find $\\(s\\)$.  \n",
    "The noise $\\(e\\)$ makes the problem hard.\n",
    "\n",
    "### Module‑SIS  \n",
    "Find a short vector $\\(x\\)$ such that:\n",
    "\n",
    "$A \\cdot x = 0 \\pmod{q}$\n",
    "\n",
    "Both problems are NP‑hard under quantum attacks.\n",
    "\n",
    "Dilithium uses:\n",
    "\n",
    "- polynomial rings  \n",
    "- modular arithmetic  \n",
    "- structured lattices  \n",
    "- deterministic signing  \n",
    "- rejection sampling  \n",
    "\n",
    "## Algorithmic Structure\n",
    "\n",
    "### Key Generation\n",
    "1. Generate matrix $\\(A\\)$ from a seed  \n",
    "2. Choose short vectors $\\(s_1, s_2\\)$  \n",
    "3. Compute:\n",
    "\n",
    "$t = A s_1 + s_2$\n",
    "\n",
    "4. Compress $\\(t\\)$ → public key\n",
    "\n",
    "### Signing\n",
    "1. Choose random short vector $\\(y\\)$  \n",
    "2. Compute:\n",
    "\n",
    "$w = A y$\n",
    "\n",
    "3. Challenge:\n",
    "\n",
    "$c = H(w, \\text{msg})$\n",
    "\n",
    "4. Compute:\n",
    "\n",
    "$z = y + c s_1$\n",
    "\n",
    "5. Rejection sampling: repeat if $\\(z\\)$ too large\n",
    "\n",
    "### Verification\n",
    "Reconstruct $\\(w'\\)$ from $\\(z\\)$ and public key, check:\n",
    "\n",
    "$H(w', \\text{msg}) = c$\n",
    "\n",
    "## Properties\n",
    "\n",
    "| Property | Value |\n",
    "|---------|-------|\n",
    "| Signature size | ~2.5 KB |\n",
    "| Public key | ~1.3 KB |\n",
    "| Speed | medium |\n",
    "| Security | very high |\n",
    "\n",
    "## Practical Use Cases\n",
    "- TLS 1.3 hybrid handshake  \n",
    "- software signatures  \n",
    "- firmware updates  \n",
    "- PKI systems  \n",
    "\n",
    "Dilithium is the **default choice** for most PQC migrations.\n",
    "\n",
    "---\n",
    "\n",
    "# 🦅 **2. Falcon — The Elegant, Fast NTRU‑Lattice Algorithm**\n",
    "\n",
    "Falcon is mathematically more sophisticated than Dilithium — but delivers **tiny signatures** and **extreme speed**.\n",
    "\n",
    "## Mathematical Foundation\n",
    "\n",
    "Falcon is based on:\n",
    "\n",
    "- **NTRU lattices**  \n",
    "- **GPV sampler** (Gentry–Peikert–Vaikuntanathan)  \n",
    "- **Fast Fourier Sampling (FFS)**  \n",
    "- **Gaussian sampling in high‑dimensional lattices**\n",
    "\n",
    "### NTRU Lattice  \n",
    "Defined by polynomials $\\(f, g, q, p\\)$ and:\n",
    "\n",
    "$f * h \\equiv g \\pmod{q}$\n",
    "\n",
    "Security relies on the hardness of finding short vectors in NTRU lattices.\n",
    "\n",
    "## Algorithmic Structure\n",
    "\n",
    "### Key Generation\n",
    "1. Choose short polynomials $\\(f, g\\)$  \n",
    "2. Compute inverse $\\(f^{-1} \\mod q\\)$  \n",
    "3. Public key:\n",
    "\n",
    "$h = g / f \\pmod{q}$\n",
    "\n",
    "### Signing  \n",
    "Falcon uses the **GPV sampler**, generating:\n",
    "\n",
    "$z \\sim D_{\\Lambda, \\sigma}$\n",
    "\n",
    "A discrete Gaussian over the lattice.\n",
    "\n",
